# Align every first-read document with the current paper AIO authority

The root onboarding documents still described pre-recovery AM-TNC execution,
CycleGAN co-residency on 5090B and older local terminal control PIDs. Those
statements were once accurate, but they could cause a fresh controller to
restart the wrong runtime, wait for an already completed predecessor or revive
an archived route-1 queue.

The current-status sections now describe the source-bound AM-TNC recovery,
exclusive 5090B matched plain, durable local terminal lock handoff and the
archive-only status of historical RF/G3 successors. Rapidly changing epochs and
PIDs remain delegated to the three JSON authority files rather than being
copied into prose.

Historical scientific sections are preserved. No training, checkpoint,
algorithm, protocol, performance value or confirmation boundary changed.
