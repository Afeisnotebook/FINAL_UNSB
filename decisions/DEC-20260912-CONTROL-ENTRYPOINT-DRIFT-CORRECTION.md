# Restore the current paper AIO control entrypoint

`PROJECT_STATE.json` carried a current paper-AIO `phase` beside a stale
top-level `next_gate` from the archived RF-AMMCRB/RF-MCRB/G3 route1 chain.
Because both fields were top-level, a fresh controller could reasonably follow
the obsolete action text and drift away from the active full-data paper goal.

The top-level action gate now names the actual fixed-protocol e200 training,
source-bound delivery, legal matched evaluation, terminal audit, complexity and
paper-portfolio path. Historical route1 evidence remains in the repository, but
its embedded successors are explicitly non-authoritative and must not be
started from archived fields.

This is a control-plane correction only. It does not stop or start training,
change an algorithm or protocol, inspect performance values, open
confirmation20, or authorize cross-runtime delta merging.
